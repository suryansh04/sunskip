# Officials portal: build plan (11 Oct 2026)

**Goal:** the officials portal in `portal/`, built in priority order so each screen is demo-ready on its own before the 14:00 feature freeze.

**Spec:** `docs/design.md` §12 (look, screens, states, motion, words) and `docs/TRD.md` §4 (routes, login, deploy). Endpoints: `docs/api.md` §8 (13–17) plus `GET /shade/segments` for path lines in the simulator. No API change is planned; any gap is asked about first (CLAUDE.md rule 6).

## Global constraints

- Vite + React + Tailwind, only the packages in TRD §2.1 (no auth library, no chart library, no react-map-gl). MapLibre is used directly.
- `types.ts`, `api/client.ts`, `MapView.tsx` and the fixtures are copied from `app/` and change together (TRD §2.6).
- Hooks: `useState`, `useEffect`, `useRef` only. One component per file. Every screen has loading, error and empty states.
- Words: "people a day" marked as an estimate, "sun-minutes saved a day", ₹ with "est.", "Unnamed path", never "safe". Unknown is shown as unknown, never 0.
- Desktop-first, 1280 px and up. Motion off under `prefers-reduced-motion`.
- Login: Cognito hosted page with **code + PKCE** and a refresh token (replaces the implicit grant in TRD §4.1; TRD updated with it).

## Build order

Each step: build, check in Chrome against the local API (all states, no page errors), `npm run build`, commit. Deploy after steps 2, 4 and 6.

1. **Scaffold + Heat pain (`/`).** Project, top bar with tabs and area picker (MUJ and Bus 26 stop, Mansarovar Metro), Signal map style, banded list, finding sentence, rank tags, hover highlight both ways, Month and Hours cells (10 AM – 4 PM or one hour), CSV export, preparing banner, `409` and error states.
2. **Stretch evidence (`/stretch/:id`).** Four numbers, 12 × 24 sun grid with hover read-out, who walks here, line drawing with scale and north arrow, sources, A4 landscape print.
3. **Trees and shelters (`/recommendations`).** Type cells, budget cells with Indian grouping, plan total, rows with before → after bar, open row with reason, "Try in 3D", "Evidence"; map pins; no-fit state.
4. **What-if simulator (`/simulate`).** 3D map (pitch 60°, building extrusions), add / move / select trees and shelters drawn with fill-extrusion, item editor, Run → `POST /portal/simulate`, sun-minutes saved, hourly before/after bars, changed paths recoloured with a Before / After switch.
5. **Usage (`/stats`).** 7 / 30 / 90 days, four numbers, top start points as list and circles.
6. **Sign in + deploy.** `/login`, `/callback`, PKCE, refresh, 401 → sign in again; second Amplify app; Cognito callback and sign-out URLs; API Gateway CORS; CI `portal` job; docs.
